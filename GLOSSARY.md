# Context

Glossary for the agentgateway Educates operator. Terms only: no implementation
detail, no decisions. Decisions live in `docs/adr/`; the design lives in
`.scratch/agentgateway-operator/`.

## Platform terms

These are Educates' terms. They are defined here only where this project's use
of them is load-bearing or easily confused.

**Workshop**: the definition of a piece of training content. A template, not a
running thing.

**Workshop environment**: a deployed instance of a Workshop, capable of hosting
many sessions. Owns the **workshop namespace**.

**Session**: one attendee's live instance of a workshop. The unit of identity
in this project: one session, one **participant key**. Owns the **session
namespace**.

**Workshop namespace**: the namespace holding the workshop environment,
including the Deployment that runs each attendee's dashboard container. Named by
`$(workshop_namespace)`.

**Session namespace**: the per-attendee namespace. Named by
`$(session_namespace)`. Distinct from the workshop namespace, and *not* where
the attendee's container runs. Educates owns session objects by this namespace,
so its deletion is what garbage-collects them.

**Session object**: a resource declared in a Workshop's `session.objects` and
created by Educates when a session starts. This project's **session grant** is
one.

## Project terms

**Gateway**: the shared, cluster-wide agentgateway instance that proxies LLM
traffic for every workshop. One per cluster. Installed by Helm, not by this
operator.

**Gateway namespace**, where the Gateway and its policy live. Significant
because agentgateway resolves credentials only within this namespace, which is
what separates a **participant key** from its **key registration**.

**Session grant**: an attendee's access to the Gateway for the duration of one
session. The custom resource an author declares in `session.objects`. Named for
what it confers, not for the credential that implements it: the key is an
implementation detail of the grant, and a grant may outlive any particular key
(see **key rotation**).

**Participant key**: the credential an attendee's workshop code uses to reach
the Gateway. Generated by this operator, never by an upstream service. Its
plaintext exists in exactly one place: a Secret in the workshop namespace,
injected into the attendee's container as an environment variable. Deliberately
avoids the term "virtual key", see below.

**Key registration**: the record that makes the Gateway accept a **participant
key**: the key's hash and its metadata, held in the gateway namespace. Contains
no key material. Its separation from the participant key, different namespace,
different lifecycle, different contents, is the central awkwardness of this
design, recorded in [[ADR-0002]].

**Key rotation**, replacing a participant key while its **session grant**
persists. What happens when the key's Secret is absent but the grant is not: a
new key is generated and its registration updated. The grant is stable; the key
is not.

**Model catalog**: the set of LLM backends the Gateway offers, declared once
per cluster in this project's terms and rendered into agentgateway's own
resources. Attendees address models by catalog name only.

**Catalog model**: one named entry in the **model catalog**: a name an attendee
may use, bound to a provider and an upstream model. The name is deliberately not
the upstream model's name, so that the binding can change without touching
workshop content.

**Upstream model**: the provider's own model, named in the provider's terms.
Never visible to attendees.

**Provider credential**: the real, long-lived API key for an LLM provider,
shared by every session. Held in a Secret referenced by name from the model
catalog, so that no credential material appears in any custom resource. Not to
be confused with a **participant key**, which is per-session, short-lived, and
generated here.

**Token budget**: the per-session ceiling on LLM tokens for one **budget
window**, enforced by the Gateway against an external rate-limit service. Guards
the shared **provider credential** against a single runaway attendee. Measured
in tokens rather than requests because one request with a large context can cost
more than a hundred small ones. It counts every model's tokens the same, so a
**cost budget** is the more precise ceiling where models differ in price; the
token budget remains because it cannot be skipped, which makes it the backstop
(ADR-0009).

**Cost budget**: the per-session ceiling on spend for one **budget window**,
expressed in US dollars. Priced per request by agentgateway against its own
model cost catalog, so an expensive **catalog model** drains it faster than a
cheap one and the ceiling means the same thing whichever model an attendee
picks. Enforced alongside the **token budget**, never instead of it, and
reachable without the database ADR-0001 rejected (ADR-0009).

**Budget window**: how long one budget lasts before it refills, governing the
**token budget** and the **cost budget** alike. Defaults to a day, which
outlasts a workshop. Not a session lifetime: no lifetime-scoped budget exists in
this stack, and windows align to the Unix epoch rather than to a session's first
request (ADR-0009). Distinct from the grant's TTL, which expires the
**participant key** itself.

## Terms deliberately avoided

**Virtual key**, LiteLLM's term, and the term this project started with. Avoided
because it names a different thing: in LiteLLM a virtual key is minted by the
proxy, recorded in its database, and carries server-side identity. Here the
credential is generated by the operator, stored nowhere upstream, and known to
the Gateway only as a hash. Use **participant key**.

**User**, ambiguous between the attendee, the cluster operator installing the
platform, and the workshop author writing content. Say which.

**Install CRD**: an early framing of the **model catalog**, discarded once the
Gateway's installation moved to Helm. The catalog configures a Gateway; it does
not install one.
